# 필요한 폰트

폰트 바이너리는 저장소에 포함하지 않는다. 아래 파일을 사용자가 직접 준비해 이 폴더에 둔다.

- `dalmoori.ttf`
- `NanumGothic.ttf`
- `NanumGothicBold.ttf`
- `NanumGothicExtraBold.ttf`
- `NanumMyeongjo.ttf`
- `NanumMyeongjoBold.ttf`
- `NanumMyeongjoExtraBold.ttf`

작은 픽셀 글꼴은 렌더러가 필요할 때 다음 공개 CDN에서 자동으로 내려받을 수 있다.

- `pixel/Tangba12.woff2`: `https://cdn.jsdelivr.net/gh/projectnoonnu/2601-4@1.1/Tangba12.woff2`
- `pixel/DungGeunMo.woff`: `https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_six@1.2/DungGeunMo.woff`

공개 배포 전에는 각 폰트의 원 저작권과 라이선스를 직접 확인해야 한다.
